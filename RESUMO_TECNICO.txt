🔧 DETALHES TÉCNICOS

FUNÇÃO: positionDrawer()
┌─────────────────────────────────────────────────────────────────────────┐
│ Responsável por posicionar o popover de contatos dinamicamente          │
│                                                                          │
│ Algoritmo:                                                              │
│ 1. Encontra a aba ativa (elemento com classe crm-pill-on)              │
│ 2. Obtém as coordenadas da aba (getBoundingClientRect)                 │
│ 3. Calcula posição abaixo da aba (rect.bottom + 10px)                  │
│ 4. Centraliza horizontalmente: left = rect.left + (rect.width - 420)/2 │
│ 5. Ajusta se sair da tela (horizontal):                                │
│    - Se left < 8: left = 8                                             │
│    - Se left + 420 > viewport.width - 8: left = viewport.width - 428   │
│ 6. Ajusta se sair da tela (vertical):                                  │
│    - Se top + height > viewport.height - 8: abre acima                 │
│ 7. Aplica estilos CSS (top, left, transform)                           │
│                                                                          │
│ Complexidade: O(1) - operações constantes                              │
│ Performance: < 1ms em máquinas modernas                                 │
└─────────────────────────────────────────────────────────────────────────┘

VARIÁVEL: drawerAnchor
┌─────────────────────────────────────────────────────────────────────────┐
│ Armazena referência ao elemento que acionou o drawer                    │
│ Tipo: HTMLElement | null                                               │
│ Inicialização: null                                                     │
│ Atualização: Em filterByLabel() e filterByStage()                       │
│ Limpeza: Em closeDrawer()                                               │
│ Propósito: Permitir posicionamento correto mesmo após re-render         │
└─────────────────────────────────────────────────────────────────────────┘
